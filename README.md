# SERVORA

### Hyperlocal On-Demand Service Marketplace

Servora connects customers with nearby service providers for fast, reliable and convenient local services.

## Features

- Customer service requests
- Nearby service-provider discovery
- Provider registration
- Service categories
- Real-time request matching
- Location and map integration
- OTP-based authentication
- Live service tracking
- Service booking and status management
- Digital payments
- Provider availability management

## Service Categories

- Electrical Services
- Plumbing
- Appliance Repair
- Cleaning
- Photography
- Flex & Printing
- Event Services
- Organizers
- Architecture & Design
- Other Local Services

## Tech Stack

Frontend:
- React Native
- JavaScript / TypeScript

Backend:
- Node.js
- Express.js

Database:
- PostgreSQL
- PostGIS

Other Technologies:
- Socket.IO
- Google Maps API
- OTP Authentication
- Payment Gateway

## Project Architecture

Customer App → API → Backend → PostgreSQL/PostGIS
                         ↓
                  Service Providers
                         ↓
                  Real-time Tracking
